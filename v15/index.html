How I work

  • Pain point before solution. Find the layer the bottleneck lives in before building.
  • Staged rollout and attribution. One layer of change per stage, so a problem points at its layer.
  • Define the metric before the number. Every number names its dashboard, metric and read date.
  • Cost is a product parameter. A shadow run proves quality holds before cost is cut.
