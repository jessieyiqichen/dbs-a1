How I work

  1. Pain point before solution. Confirm which layer the bottleneck lives in before building.
  2. Staged rollout and attribution. One layer of change per stage, so a problem points at its layer.
  3. Define the metric before the number. Every number names its dashboard, its metric and its read date.
  4. Cost is a product parameter. A shadow run proves quality holds before cost is cut.
