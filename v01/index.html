Account II · Bookkeeping rules four, across every project

  1. Pain point before solution. Confirm which layer the bottleneck lives in before building. Get the layer wrong and no feature fixes it.
  2. Staged rollout and attribution. One layer of change per stage, so a problem points at its layer immediately.
  3. Define the metric before the number. Pick a North Star that reflects real value; any number in a report must name its dashboard, metric and read date.
  4. Cost is a product parameter. Every model call is logged; before cutting cost, a shadow run proves quality holds. Savings are the result of verification, not the goal.
