How I work

  1. Pain point before solution. Confirm which layer the bottleneck lives in before building. Get the layer wrong and no feature fixes it.
  2. Staged rollout and attribution. One layer of change per stage, so a problem points at its layer immediately.
  3. Define the metric before the number. A North Star that reflects real value; any reported number names its dashboard, metric and read date.
  4. Cost is a product parameter. Every model call logged; a shadow run proves quality holds before cost is cut.
