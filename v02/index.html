Four things that run through all five

Pain point before solution.

Confirm which layer the bottleneck lives in before building. Get the layer wrong and no feature fixes it.

Staged rollout and attribution.

One layer of change per stage, so a problem points at its layer immediately. Three stages, two days, zero rollbacks.

Define the metric before the number.

Marks reviewed after class, not marks made in class. Daily actives by UV, not PV. Every reported number names its dashboard and read date.

Cost is a product parameter.

Every model call logged and routed by task tier. A shadow run proves quality holds before cost is cut.
