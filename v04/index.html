How I work

  • Pain point before solution. Confirm which layer the bottleneck lives in before building; get the layer wrong and no feature fixes it.
  • Staged rollout and attribution. One layer of change per stage, so a problem points at its layer immediately.
  • Define the metric before the number. Marks reviewed after class, not made in class; daily actives by UV, not PV.
  • Cost is a product parameter. Every model call logged and routed by tier; a shadow run proves quality holds before cost is cut.
